# Exploratory Data Analysis (EDA) Projects

## Overview

This directory contains Exploratory Data Analysis (EDA) projects performed on real-world datasets from domains such as healthcare, insurance, retail, customer behavior, and product analytics.

The primary objective of these projects is to understand data characteristics, identify patterns and trends, detect anomalies, evaluate data quality, and derive meaningful business insights before building machine learning models.

Exploratory Data Analysis is a critical step in the data science lifecycle, helping analysts make informed decisions regarding feature engineering, model selection, and business strategy.

## Projects Included

### Medical Cost Analysis

* Dataset: Medical Insurance Cost Dataset
* Objective: Analyze factors affecting medical insurance expenses.
* Key Areas:

  * Age and insurance cost relationship
  * BMI impact on charges
  * Smoker vs Non-Smoker comparison
  * Regional expenditure patterns

### Shopper Behavior and Revenue Analysis

* Dataset: Shopper Behavior and Revenue Dataset
* Objective: Understand customer purchasing behavior and revenue generation patterns.
* Key Areas:

  * Customer activity analysis
  * Revenue contribution patterns
  * Behavioral segmentation
  * Feature relationship assessment

### Wine Quality Analysis

* Dataset: Wine Quality Dataset
* Objective: Explore factors influencing wine quality ratings.
* Key Areas:

  * Feature distributions
  * Correlation analysis
  * Quality score trends
  * Variable importance identification
