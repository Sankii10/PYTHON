# K-Nearest Neighbors (KNN) Regression Projects

## Overview

This directory contains Machine Learning Regression projects developed using the K-Nearest Neighbors (KNN) Regressor algorithm. These projects demonstrate the application of instance-based learning techniques for predicting continuous numerical values across domains such as healthcare, insurance, retail, economics, and real estate.

KNN Regression is a non-parametric supervised learning algorithm that predicts target values based on the average of the nearest neighboring observations in the feature space.

## Objectives

* Develop predictive models using KNN Regression.
* Analyze relationships between independent variables and continuous target variables.
* Evaluate model performance using regression metrics.
* Compare KNN Regression performance across multiple datasets.
* Generate actionable business insights through predictive analytics.

## Evaluation Metrics

The models are evaluated using one or more of the following metrics:

* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
* Root Mean Squared Error (RMSE)
* R² Score
* Cross-Validation Score
